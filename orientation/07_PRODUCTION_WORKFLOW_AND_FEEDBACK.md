## PURPOSE

Practice production and feedback without promoting history into canon.

## WHAT THIS STAGE GOVERNS

Shared production snapshots, project memory and scoped critique.

## WHAT THIS STAGE DOES NOT GOVERN

Automatic approval, rerolling saved decisions or formal PASS/RETRY tests.

## BOUNDED CONCEPTS

After final calibration, configure image direction in the Art Director and create a Prompt or JSON. Both outputs consume one resolved ProductionSpec; they must not independently reinterpret editable state. Random and inherited choices become concrete before production. Save does not reroll them.

Save Project preserves editable project state, available resolved production, feedback, exemplar originals and generation history. Load validates atomically. Incomplete Subject/Theme projects can still be saved without fabricating ProductionSpec. Global user presets remain separate. Artistic advisories do not prevent Save or Load.

History is evidence, not authority. Record liked/disliked features, next change, endorsement and its scope. Reload guidance asks the oriented agent to inspect the dossier and context, then provide an Understanding Check conversationally. Exact originals and JSON/TXT remain authoritative where thumbnails or PDF presentation simplify display.
