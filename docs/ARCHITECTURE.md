# Application architecture

React/TypeScript/Vite static browser application; native CSS variables for restrained Light/Dark UI. Ajv validates versioned contracts, JSZip implements portable packages, pdf-lib/fontkit generate dossiers. Browser File/Blob APIs preserve originals; localStorage stores UI appearance and global user presets. No backend.

src/state owns contracts/resolution; src/color perceptual color utilities; src/randomization committed choices; src/presets reuse; src/validation advisories; src/export shared snapshot; prompt-compiler/json-compiler aligned output; project-package atomic ZIP memory; pack-loader curated registry and Community overlay; pdf dossiers; tabs/components/app UI; styles design tokens.

Community UI is lazy-loaded. The pure registry overlay lives in community-registry.ts so the initial workspace does not pull in ZIP exchange merely to combine metadata. Project packaging and PDF generation remain demand-loaded. Larger pdf-lib/fontkit chunks are acceptable work performed on Save, not grounds for complex optimization.

Dossiers use DejaVu Sans for Latin Extended, European accents, punctuation and common symbols. A renamed OFL-1.1 Noto-derived gzip-compressed TrueType fallback supplies core Simplified Chinese, Japanese kana/ideographs and Korean Hangul. It loads only for those script ranges and decompresses with the browser DecompressionStream API, then embeds a subset into each dossier. Text wrapping measures the selected per-character font; consecutive runs share a font. This is practical fallback, not a shaping/typesetting engine. Rare unsupported glyphs still disclose codepoints; exact text remains in JSON/TXT. Regional ideographs use the SC fallback shape. Emoji, rare extension ideographs and complex-script typography are outside tested coverage. Font license notices and optional reproducible subset tool are bundled; no proprietary font files.

Orientation Markdown is editable and PDFs are generated by scripts/render-orientation.py with ReportLab. references.json preserves original asset paths/hashes and governance. Documents explicitly reference, rather than embed, exemplar images. Public distribution now includes the 15 user-attested primary sheets; supporting references remain unresolved. The agent inspects relevant local originals in the full development package.

Release tooling inventories and hashes source assets, excludes unresolved corpus and private evidence from public candidates, sanitizes only copied manifests, and leaves canon untouched. Public library validation loads the same runtime registry against packs containing exact attested primary sheets and sanitized supporting references. PUBLIC_RELEASE_CONTENTS.json verifies inclusion and hashes. Full development ZIP retains originals and complete integration evidence. Manual Pages builds use the public-safe library. Neither tooling nor verification publishes anything.

Historical PlaceholderTab is retained solely for the unchanged Phase 2 regression tests and is not imported by the live application. Earlier review reports/screenshots remain private development evidence. Runtime dependency declarations/notices are preserved in THIRD_PARTY_NOTICES.md and copied into public site licenses/.
